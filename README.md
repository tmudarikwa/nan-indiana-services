# Backend

This folder contains the backend service for the Nan Indiana project.

## Overview

- API and server logic
- Data processing and business rules
- Configuration and environment setup

## Getting started

1. Open the backend folder in your terminal.
2. Create and activate a virtual environment if needed.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure environment variables for your local or deployment setup.
5. Run the backend app:

   ```bash
   python app.py
   ```

   If your project uses a different framework entry point, replace this command accordingly.
